# **Анализ экспериментальных результатов и выводы**

В рамках работы были проведены вычислительные эксперименты для оценки площади пересечения трёх окружностей методом Монте-Карло. Были рассмотрены две прямоугольные области, в которых происходила генерация случайных точек:

1. **Узкая область** — минимальный по размеру прямоугольник, содержащий только область потенциального пересечения окружностей.
2. **Широкая область** — прямоугольник, охватывающий полностью все три окружности.

Для количества точек N от 100 до 100000 (шаг 500) были построены графики:

* [График приближённых значений площади](src/approx_values.png)
* [График относительного отклонения](src/relative_error.png)

# **1. Поведение оценок площади**

### **Узкая область**

График показывает плавное и монотонное приближение значений к точной площади. Уже начиная примерно с N равного 3000–5000, разброс значений становится относительно небольшим, и дальнейшее увеличение числа испытаний улучшает точность предсказуемо и стабильно.

### **Широкая область**

Кривая демонстрирует значительно большую волатильность:

* При малых N оценки сильно «скачут».
* Даже при N равного 20000–30000 встречаются заметные отклонения.
* Сходимость есть, но она значительно медленнее.

Это соответствует теории: при увеличении площади области выборки уменьшается вероятность попадания точки в искомую фигуру, что приводит к **росту дисперсии оценки**.

---

# **2. Поведение относительного отклонения**

### **Узкая область**

* Относительное отклонение падает намного быстрее.
* При любом N ошибка ниже 5%.
* При N > 20000 ошибки обычно находятся в пределах 1–2%.

### **Широкая область**

* На малых N ошибка может превышать 5%.
* Падение ошибки идёт медленнее и неравномернее.
* Даже при N = 30000–40000 возможны всплески ошибки более 2%.

Это объясняется тем, что при большой области доля «полезных» попаданий (точек внутри пересечения трёх кругов) очень мала, и оценка получается **шумной**.

---

# **3. Содержательные выводы**

1. **Уменьшение масштабов области генерации существенно повышает точность метода Монте-Карло.**
   Это — фундаментальный вывод: дисперсия оценки обратно пропорциональна вероятности попадания точки в целевую область. Узкая область обеспечивает гораздо большую вероятность попадания, поэтому сходимость быстрее.

2. **Для узкой области метод Монте-Карло стабильно приближается к точному значению** и уже при N > 10000 обеспечивает хорошую точность.

3. **Широкая область приводит к значительному ухудшению точности**, особенно при малых и средних N. В этом случае необходимы либо:

   * многократное увеличение числа испытаний,
   * либо геометрические способы сужения области.

4. **Практический вывод**:
   При использовании метода Монте-Карло важно минимизировать объём области, в которой происходит выборка, если только это возможно аналитически. Это значительно ускоряет сходимость и уменьшает вычислительные затраты.
