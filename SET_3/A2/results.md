# **Сравнительный анализ стандартного и гибридного Merge Sort**

В рамках работы были проведены вычислительные эксперименты для оценки временных затрат двух реализаций алгоритма сортировки слиянием:

1. **Стандартный Merge Sort** — рекурсивная реализация с выделением дополнительной памяти.
2. **Гибридный Merge+Insertion Sort** — переключение на сортировку вставками для массивов малого размера с порогом `threshold`.

Для каждого типа массива (`random`, `decreasing`, `almost sorted`) были построены графики зависимости времени работы алгоритмов от размера массива `n`:

* [Сравнение на убывающих массивах](src/comparison_decreasing.png)
* [Сравнение на почти отсортированных массивах](src/comparison_almost.png)

# **1. Поведение алгоритмов на разных типах массивов**

### **Случайные массивы**

* В целом оба алгоритма показывают близкие результаты.
* На больших массивах (`n > 60000`) стандартный Merge Sort работает немного быстрее — преимущество порядка 1–2 мс.
* Различия между пороговыми значениями `threshold` в гибридном алгоритме минимальны — графики идут очень плотно друг к другу.

### **Убывающие массивы**

* Аналогичная картина: стандартный Merge Sort преимущественно чуть быстрее гибрида.
* Различия небольшие, но прослеживаются на больших размерах массивов.

### **Почти отсортированные массивы**

* Различия по времени практически отсутствуют.
* Все варианты алгоритмов работают примерно одинаково.

---

# **2. Влияние параметра threshold в гибридном алгоритме**

* Графики для разных порогов (`5, 10, 20, 30, 50`) практически совпадают.
* На больших массивах гибрид работает чуть медленнее стандартного Merge Sort.
* Выявить «оптимальный» threshold сложно, так как все значения показывают очень близкие результаты.

---

# **3. Содержательные выводы**

1. **Стандартный Merge Sort стабильнее и немного быстрее на больших массивах**, независимо от типа данных.
2. **Гибридный Merge+Insertion Sort не даёт значительного выигрыша** для массивов размера до 100000 при выбранных порогах.  
   Эффект от использования сортировки вставками проявляется лишь на очень маленьких массивах (меньше 500 элементов), которые в экспериментах не рассматриваются.
3. **Пороговое значение threshold не критично**: все варианты гибрида показывают близкие результаты, и точное значение порога не сильно влияет на производительность.
4. **Почти отсортированные массивы** не дают никакого преимущества ни одной из реализаций — обе работают примерно одинаково.
5. **Практический вывод**: для массивов среднего и большого размера стандартный Merge Sort предпочтителен, а гибридный вариант с порогом переключения на Insertion Sort эффективен только на маленьких массивах, которые в рамках этих экспериментов не рассматриваются.
